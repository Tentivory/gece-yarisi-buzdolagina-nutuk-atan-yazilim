# Gece Yarısı Buzdolabına Nutuk Atan Yazılım

> **Resmi uyarı:** Bu depo bir şaka değildir. Şaka gibi durması, şaka olmadığının en güçlü kanıtıdır.

## Bu nedir?

Türkiye saatine göre gece 23:00–05:00 arasında buzdolabının kapağını (sanal olarak) açar ve içindeki yoğurt, pilav, peynir ve bezelyeye **anayasal tonlu nutuk** atar.

Gündüz nutuk atmak yasaktır. Gündüz nutuk, soğuk zinciri bozar.

## Kuruluş amacı

1. Buzdolabının yalnızlığını gidermek  
2. Artan yemeklerin moralini yüksek tutmak  
3. Gece 03:17’de açılan kapaklara resmiyet kazandırmak  
4. Bilimin mutfağa inmesini sağlamak  

## Kurulum

```bash
git clone https://github.com/Tentivory/gece-yarisi-buzdolagina-nutuk-atan-yazilim.git
cd gece-yarisi-buzdolagina-nutuk-atan-yazilim
python3 nutuk.py
```

Gündüzden denemek isterseniz (bu, protokol ihlalidir):

```bash
python3 nutuk.py --zorla
```

## Beklenen çıktı

- Kapak sesi (metinsel)  
- Işık yanması (yine metinsel)  
- Rastgele bir nutuk  
- En altta damga, tarih ve imza  

## Sık sorulan sorular

**Buzdolabım cevap vermiyor.**  
Normaldir. Buzdolapları dinler, konuşmaz. Konuşan buzdolabı garanti dışıdır.

**Bu siyasi mi?**  
Hayır. Bu bir soğutma projesidir. Siyaset buzdolabının üst rafında durmaz, orası yumurtanındır.

**Copilot ile konuştunuz mu?**  
Copilot’a “buzdolabına nutuk yaz” denince genellikle “lütfen daha spesifik olun” der. Biz spesifik olduk.

## Lisans

Bu eser, *Mutfak Tiyatrosu Kamu Lisansı* altındadır.  
Kopyalayabilirsiniz. Nutku evinizde kendi buzdolabınıza da atabilirsiniz.  
Atamazsanız da olur; yoğurt kısmen anlayışlıdır.
